# Corpus d'entreprise fictif NovaTech Industries

Ce corpus est destiné au développement et à l'évaluation d'un RAG d'entreprise.

## Volume
- Documents métier : 104
- Français : 94 (90%)
- Anglais : 10 (10%)
- Répartition formats : {'.pdf': 62, '.docx': 17, '.md': 20, '.txt': 5}
- Répartition départements : {'quality': 26, 'products': 34, 'support': 24, 'hr': 20}

## Cas difficiles inclus
- versions actives et obsolètes ;
- doublon exact d'une procédure ;
- PDF scanné nécessitant de l'OCR ;
- documents confidentiels RH ;
- contenu de test de prompt injection ;
- identifiants exacts d'incidents ;
- PDF, DOCX, Markdown et TXT ;
- quelques sources techniques en anglais ;
- tableaux et documents multi-pages ;
- données structurées CSV ;
- jeu d'évaluation RAG / SQL / sécurité.

La majorité du corpus est volontairement en français pour représenter une entreprise française.
